1. What is the benefit of learning JavaScript?

The main benefit is that JavaScript is the only language the browser understands, so any website needs it. If I learned Python or Java first, I'd still have to come back and learn JavaScript later. So I might as well start there.
It's also easy to start, I don't have to say what type each variable is, and I can just open a browser and run my code right away.

2. What type of applications can be built with JavaScript?

Pretty much everything:
- Websites
- The back end, using Node.js
- Phone apps, using React Native
- Desktop apps — Slack, Discord, and VS Code are all built this way
- Real-time stuff like live chat and live scores
- Browser games

The one thing it's not good for is data science and machine learning. For me that's Python's job.

3. Which programming language is good for beginners to learn (according to Michael's perspectives)?

Michael says JavaScript is the best first language. Python is second, it's easy and forces you to indent your code neatly. Michael also says PHP is easy, but he doesn't really recommend it because the pay and job demand are low.

4. Which programming language is not good for beginners to learn, as their first language (according to Michael's perspectives)?

Ruby is his worst pick. It's too "magical", Rails writes a hundred lines of code for you, so a beginner never actually sees how anything works.
He also says don't start with Objective-C, Swift, or C++, and that Java and C# are better as your second or third language because they make you declare types before you understand why.

5. Study how the 5 core building blocks are implemented from one language to another. What are your observations? Are they similar? Different? Which of these programming languages are you already familiar with?

The five blocks are variables, if/else statements, loops, functions, and OOP. My observation is that they're all similar. Every language does the same five things, and really only the punctuation changes.

The differences are mostly about how strict each language is. JavaScript, PHP, C++, and Java use curly braces and semicolons, while Python uses spaces and Ruby uses end. C++ and Java also make you say int or string up front, and OOP is where they split the most — Java is long and formal, Ruby is really short.

So the syntax is the easy part. The real skill is knowing which block to use to solve a problem, and that carries over to any language.

The languages I'm familiar with are Python, Java, and JavaScript. I can read and write all three, but I still need Google open to see syntax and any other things i can use in each langauage.

6. Anything else I learned?

The biggest thing: frameworks like React and Django aren't magic. They're just code someone else wrote using those same five blocks.

I also like the point that you shouldn't get too attached to one language. He compares it to only ever eating food from one country you can't really say what's best if you've only tried one thing.
